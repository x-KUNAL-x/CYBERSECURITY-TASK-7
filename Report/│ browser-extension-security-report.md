## 5. How Malicious Extensions Can Harm Users

Malicious or poorly designed browser extensions can create several security and privacy risks.

### 🔴 Data Theft

A malicious extension may attempt to access or collect sensitive information entered into websites.

### 🔴 Browsing Tracking

Some extensions may monitor browsing activity and collect information about the websites a user visits.

### 🔴 Fake Advertisements and Pop-ups

Suspicious extensions may inject unwanted advertisements, pop-ups, or redirects into websites.

### 🔴 Malware and Additional Threats

A malicious extension may download or introduce additional unwanted software, depending on the permissions and capabilities it has.

---

## 6. Security Best Practices

To stay protected from suspicious browser extensions:

* Install extensions only from trusted sources.
* Check the developer before installing an extension.
* Review requested permissions carefully.
* Remove extensions that are no longer required.
* Avoid extensions from unknown sources.
* Keep the browser and extensions updated.
* Regularly review installed extensions.
* Be cautious of extensions requesting excessive permissions.
