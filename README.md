# 🧩 CYBER-SECURITY-TASK-7

## Identify and Remove Suspicious Browser Extensions

### 📌 Objective

The objective of this task is to learn how to identify potentially harmful, suspicious, or unnecessary browser extensions and understand the security risks they can create.

Browser extensions can improve functionality, but some extensions may request excessive permissions, collect user information, display unwanted advertisements, redirect websites, or potentially expose sensitive browsing data.

---

## 🛠️ Tools Used

* 🌐 Google Chrome / Mozilla Firefox
* 🔧 Browser Extension Manager
* 🔍 Extension Permissions and Reviews
* 💻 Web Browser Security Settings

---

## 🔎 Task Performed

The following steps were performed during the browser extension security review:

1. Opened the browser's extension/add-ons manager.
2. Reviewed the installed extensions.
3. Checked extension names, permissions, and usage.
4. Looked for suspicious or unnecessary extensions.
5. Identified extensions that were no longer required.
6. Removed suspicious or unnecessary extensions where applicable.
7. Restarted the browser.
8. Checked the browser for normal performance after removal.
9. Researched the security risks associated with malicious browser extensions.

---

## 🚩 Warning Signs of a Suspicious Extension

An extension should be reviewed carefully if it:

* Requests unnecessary permissions.
* Has a suspicious or unknown developer.
* Has very few or poor-quality reviews.
* Has not been updated for a long time.
* Changes the browser's search engine or homepage without permission.
* Displays unexpected advertisements or pop-ups.
* Redirects websites unexpectedly.
* Collects more browsing information than necessary.
* Comes from an untrusted source.

## 🗑️ Removal Process

The general removal process was:

1. Open the browser.
2. Navigate to the **Extensions / Add-ons** manager.
3. Review the installed extensions.
4. Select the suspicious or unnecessary extension.
5. Choose **Remove**.
6. Confirm the removal.
7. Restart the browser.
8. Verify that the extension is no longer installed.

---

## ⚠️ Security Risks of Malicious Browser Extensions

Malicious or compromised browser extensions can potentially:

* Monitor browsing activity.
* Collect sensitive information.
* Read or modify website content.
* Redirect users to malicious websites.
* Inject unwanted advertisements.
* Track browsing behavior.
* Attempt to steal session information.
* Reduce browser performance.
* Introduce additional security risks.

The actual impact depends on the permissions granted to the extension and what the extension's code is designed to do.

---

## 🛡️ Browser Extension Security Best Practices

* Install extensions only from trusted sources.
* Check the developer before installing an extension.
* Review requested permissions carefully.
* Remove extensions that are no longer needed.
* Keep browsers and extensions updated.
* Check reviews and user feedback.
* Avoid extensions from unknown websites.
* Periodically audit installed extensions.
* Use the minimum number of extensions necessary.
